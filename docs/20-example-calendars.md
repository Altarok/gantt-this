# Example calendars

> The following files can be copied to your vault directly.
> There is only one frontmatter property used in Gantt calendars. It defaults to `gantt-calendar-definition`.
> You may have to rename this property when copying these calendars to your vault.

All calendars come with comments, which repeat themselves over and over.
Comments are everything behind the `'#'` symbol.
You may remove the comments starting from `'#'` completely.

For this plugin all calendars are day-based, there is no time of day.
This may change later, see [[90-roadmap|Roadmap]] for planned features.
